# Soundscape Sydney

This project is part of my doctoral research:

"Extending Soundscapes: 360° Virtual Environments and Ambisonics Representation toward Sustainable Listening"

## Overview
Soundscape Sydney is an interactive mobile application that allows users to explore urban sound environments through immersive audio experiences.

## Features
- Location-based sound mapping
- Ambisonic and 360° audio playback
- Layered sound categorisation (biophony, geophony, anthropophony)
- Live transmission and archive system
